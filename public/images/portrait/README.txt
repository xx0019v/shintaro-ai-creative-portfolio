Place the 4 portrait/character images here with these filenames:

  portrait-headshot.png   ← close-up head shot with sunglasses
  portrait-full-01.png    ← full body, hand on hip
  portrait-full-02.png    ← full body, arms crossed
  portrait-full-03.png    ← full body, holding tablet

The site code references these paths via /images/portrait/*.png.
They appear in the Hero (silhouette accent), About (editorial portrait),
and Contact (signature visual).

If a file is missing the site still renders — only the empty silver frame shows.
